餐點配方

依家 POS 可以駁咩機

大多數市面 ESC/POS 熱敏出單機 都得：佳博、Epson TM 系列、Xprinter、商米外置機。用 USB 插 店舖 Sunmi 或 電腦版 Chrome。iPhone Chrome／Safari 都駁唔到 USB；Epson App 配對只得個 App 用。

Epson TM-m30II（你而家呢部）

  1. 揭開機底蓋，USB 線插出單機，另一頭插 Sunmi 收銀機（唔好插 Windows 再期望 iPhone 印）。
  2. 開電。Sunmi 系統設定 → 打印機 → 揀呢部 Epson，協議 ESC/POS。
  3. POS 撳右上「出單機」，紙闊揀 80mm，再撳「駁 Sunmi 出單機」。
  4. 如果用店舖電腦：Chrome 開 POS，USB 插電腦，紙闊 80mm，撳「駁 USB」然後揀 Epson。

呢部 M362B 標準版冇 Lightning。iPhone 出單做唔到，要 Sunmi 或電腦。
